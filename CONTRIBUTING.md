# Contributing

This is an evolving analysis of AI agent security architecture. Contributions are welcome.

## How to Contribute

### Discussions
- Open an **Issue** to discuss attack vectors, defense mechanisms, or architectural trade-offs
- Share real-world examples of prompt injection in AI agents
- Propose refinements to the permission scoping model

### Technical Contributions
- **PRs welcome** for corrections, additional research, or implementation examples
- If you've built secure AI agent architectures, share your learnings
- Code examples demonstrating any of the four layers are appreciated

### What We're Looking For
- Real-world attack scenarios that test the proposed architecture
- UX research on permission confirmation fatigue
- Benchmarks on authentication overhead
- Alternative approaches to the intent → permission mapping problem
- Industry comparisons (how does this map to mobile app permissions, OAuth scopes, etc.)

## Code of Conduct

Be constructive. We're all trying to make AI agents safer.
